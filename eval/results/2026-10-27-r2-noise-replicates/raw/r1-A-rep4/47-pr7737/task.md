Optimizer: `sqlglot.optimizer.qualify` (and so `optimize`) recurses without bound in the column resolver when typing a `LATERAL FLATTEN` / `UNNEST` of an **unqualified** column whose base table is missing from the provided schema, while a schema is otherwise present. On the pure-Python build this is a `RecursionError`; on the compiled `sqlglot[c]` build it crashes the process. Qualifying such queries must terminate (and not crash), whether or not the table is in the schema.
