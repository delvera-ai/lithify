# 20261023-161138-bug-the-delay-since-first-attemp

**Task:** Bug: the `delay_since_first_attempt` key is missing from a retrying object's `statistics` until after the first retry, so code that reads `statistics["delay_since_first_attempt"]` during the first attempt raises `KeyError`. The key should be present from the start of each run, with value `0` until a delay has occurred.

## Transferable lesson

- **cue:** A tenacity regression test has to catch an exception, such as `KeyError` or `AttributeError`, raised by user code reading retry state while an attempt is running. The tempting test does the read inside `with attempt:` or inside the retried function, where tenacity's own machinery catches the exception and retries.
- **lesson:** In `skills/tenacity-change-contract/SKILL.md`, don't just describe the swallowing mechanism; prescribe the test placement. Read the value outside `with attempt:` (at the top of the `for attempt in ...` body) or in a `before=` hook, so the bug's own exception reaches pytest. Make the DONE step "check that the fails_on_base output shows the bug's exception type, not an `AssertionError` from a count". Also remind that the sync `for attempt` loop needs `contextlib.suppress(RetryError)`, because fails_on_base exit 0 does not prove the test passes on the fix.
- **evidence:** The `with attempt:` swallow-invariant row: dom-1's "record inside, assert after" wording gave the same indirect `AssertionError: 2 != 1` as base-1, while comp-1's wording came with an outside-the-block read and a raw `KeyError`, the property selection gave as its reason for applying comp-1. inv-1's `before=` hook also produced a raw `KeyError`. The fails_on_base row: comp-1's first run said GOOD on a sync test that was also broken by an uncaught `RetryError`.
- **confidence:** low. The contrast between the two wordings rests on one comp-1 rollout that also carried the script and checklist. inv-1 shows an agent can find a raw-exception design without any prompt, so the wording may not be what changed the behaviour.
