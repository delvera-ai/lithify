final message:
`statistics["delay_since_first_attempt"]` is now present from the start of every run, with value `0` until a delay happens. Reading it during the first attempt no longer raises `KeyError`.

**Cause:** `BaseRetrying.begin()` seeds `start_time`, `attempt_number` and `idle_for`, but the key was only written in `_run_stop`, which runs after the first attempt. The async class calls the same `begin()`, so the fix covers both.
