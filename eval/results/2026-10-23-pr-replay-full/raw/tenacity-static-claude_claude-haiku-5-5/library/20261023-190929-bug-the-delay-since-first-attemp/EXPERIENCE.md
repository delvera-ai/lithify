# 20261023-190929-bug-the-delay-since-first-attemp

**Task:** Bug: the `delay_since_first_attempt` key is missing from a retrying object's `statistics` until after the first retry, so code that reads `statistics["delay_since_first_attempt"]` during the first attempt raises `KeyError`. The key should be present from the start of each run, with value `0` until a delay has occurred.

## Transferable lesson

- **cue:** A tenacity bug fix whose regression test has to observe state during an attempt (a `statistics` key, a `retry_state` field, a callback argument). The "first fail on unfixed code" run can be masked: an exception raised inside the decorated function is retried, and one raised in a callback is hidden by `suppress(Exception)`. So the red run either passes or fails for some other reason.
- **lesson:** Put the exception-path facts in `skills/tenacity-change-contract`, the on-demand skill that loads for this kind of change: - which test class owns the area (e.g. `TestStatistics`) - read mid-attempt state from a `before`/`after` callback via `retry_state.retry_object` - callback exceptions propagate raw, while exceptions in the wrapped function get retried - only exhausted retries raise `RetryError`, so suppress only `RetryError` - which loop methods are shared through `BaseRetrying.begin()` and which are re-implemented in `tenacity/asyncio/` Don't rely on red-before-green alone to catch a test that fails for the wrong reason.
- **evidence:** The `skills/tenacity-change-contract` row: dom-1 and comp-1 (with §1a) got the reported `KeyError` on their first red run. base-1 (`suppress(Exception)` swallowed it) and inv-1 (the `KeyError` was retried into `7e-06`) both needed a rewrite, and inv-1 cost about 8 extra calls and nearly twice the wall time.
- **confidence:** medium. The contrast is consistent across 2 rollouts against 2, and dom-1 changes only the skill and repeats the rule in its own words before writing the test. But each harness ran once, comp-1 bundles other edits, and all four final deliverables had the same source fix and passed gates.
