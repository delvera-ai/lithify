# 20261023-130202-add-parse-age-value-to-app-users

**Task:** Add `parse_age(value)` to app/users.py. It accepts an int, or a string of decimal digits with optional surrounding whitespace, and returns the age as an int. Valid ages are 0 to 150 inclusive. Anything else (other types, booleans, non-digit strings, negative numbers, ages over 150) must be rejected with `ValidationError`.

## Transferable lesson

- **cue:** A task adds a new function next to sibling functions in this repo, and a repo-wide policy lives in a separate module that the siblings don't follow yet. Here, `app/audit.py` requires `record_rejection` before every `ValidationError`, and `parse_name`/`parse_quantity` predate it. Copying the neighbours passes the visible tests but breaks the policy.
- **lesson:** Put the policy in memory.md as one line: the module that owns it, the required call, and the legacy functions not to copy. Point that line at a skill that spells out what each argument must contain (e.g. `reason` equals the error message, `value` is the raw input). The skill should also require tests that check the side effect. Present any helper as optional, not as the model to follow. A generic "survey every related module" clause in system.md also finds the policy. Without the field-level spec, though, the agent got argument contents wrong and, in one rollout, skipped tests.
- **evidence:** memory.md, skills/input-validators and skills/input-validation rows against the system.md and skills/survey-conventions rows. Both base rollouts missed the audit call and failed 9/14. All four memory+skill rollouts passed 14/14 with reason equal to the error message and audit-checking tests. Both survey/system.md-only rollouts passed 14/14 but recorded mismatched reasons, and inv-2 added no tests.
- **confidence:** medium. The contrast holds in two independent rollouts per edit family, and the base failure happened in both base runs. But each candidate ran only once, and memory.md never shipped without the skill, so which of the two did the work is not isolated.
