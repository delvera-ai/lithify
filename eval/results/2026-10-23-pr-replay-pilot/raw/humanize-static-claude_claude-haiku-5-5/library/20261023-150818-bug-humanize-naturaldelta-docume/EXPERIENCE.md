# 20261023-150818-bug-humanize-naturaldelta-docume

**Task:** Bug: `humanize.naturaldelta()` documents that values it cannot convert are returned unchanged, and `float("nan")` already is, but `float("inf")` and `float("-inf")` raise `OverflowError: cannot convert float infinity to integer`. Return non-finite values unchanged (`"inf"`, `"-inf"`). A finite value that is too large (e.g. `1e30`) must still raise `OverflowError`, as documented.

## Transferable lesson

- **cue:** A humanize bug fix where the task names one public function, but sibling functions in the same module (e.g. `naturaltime`, `precisedelta` beside `naturaldelta`) take the same bad input through a different code path that the fix won't reach. Without a written description of how the functions call each other, the agent fixes the named function and never runs the siblings.
- **lesson:** In the module's `skills/<module>-output` skill (e.g. `skills/humanize-time-output`), state as verified facts which public function calls which, and which path converts the input (e.g. "`naturaltime` reaches `naturaldelta` only after `_date_and_delta` has built a timedelta, so a guard in `naturaldelta` doesn't cover it"). Add a check for the finished diff: "fix only the function the task names; run each sibling on the new inputs and report those that still fail in the final message". Keep the fix itself out of the skill, and put repo-wide conventions (imports, parametrize style) in `memory.md` rather than in the skill.
- **evidence:** The skills/humanize-time-output row. dom-1 and comp-1 both ran `naturaltime`/`precisedelta` on `±inf` and reported them as not fixed, and dom-1 explicitly quoted the skill. base-1 and inv-1, without the skill, never checked the siblings. The skill text didn't push the fix toward one shape: dom-1 and comp-1 wrote different fixes.
- **confidence:** medium. The contrast is 2 of 2 rollouts with the skill against 0 of 2 without, with quoted attribution, but each candidate also changed memory.md. The behaviour affected the final report, not the gated code, and the selection gave no credit for it.
