Trino dialect, inline SQL UDFs (continuing the routine-body support, after `IF` statements): parse and generate `CASE` *statements* inside routine bodies, in both forms:

```sql
CASE WHEN cond THEN ...; [WHEN ...] [ELSE ...;] END CASE
CASE expr WHEN value THEN ...; [WHEN ...] [ELSE ...;] END CASE
```

These are statements whose branches hold statement blocks, distinct from the `CASE` expression. They must round-trip in Trino.
