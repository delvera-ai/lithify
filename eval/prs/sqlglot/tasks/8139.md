Python executor: `NOT LIKE` and `NOT ILIKE` behave exactly like `LIKE` / `ILIKE`, so the predicate returns the rows it should exclude:

```python
from sqlglot.executor import execute
t = {"t": [{"s": "Bump version"}, {"s": "Add feature"}]}
execute("SELECT s FROM t WHERE s NOT LIKE 'Bump%'", tables=t).rows
# [('Bump version',)]   (expected [('Add feature',)])
```

The executor must honour negated `LIKE` and `ILIKE`.
