BigQuery dialect: BigQuery accepts `FOR SYSTEM TIME AS OF` (with spaces) as well as the documented `FOR SYSTEM_TIME AS OF`, but sqlglot only parses the underscore form:

```python
sqlglot.parse_one('SELECT * FROM project.dataset.table FOR SYSTEM TIME AS OF "2026-04-09" LIMIT 10', dialect="bigquery")
# ParseError: Invalid expression / Unexpected token
```

The space form should parse as well.
