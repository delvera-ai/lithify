Schema performance: `MappingSchema.find` lookups are repeated for the same table many times during `annotate_types` on wide queries (e.g. thousands of column references across a few tables). Cache these lookups so repeated calls for the same table, with the same `ensure_data_types` setting, don't redo the work. Results must be identical, and the cache must stay correct when the schema changes (e.g. when tables are added).
