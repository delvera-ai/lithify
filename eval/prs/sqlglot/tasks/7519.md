MySQL dialect: quoted index or constraint names that look like keywords are rejected. MySQL allows any identifier as an index name when it is backtick-quoted, e.g. ``UNIQUE KEY `Unique` (a)``, ``KEY `Index` (b)`` or ``UNIQUE INDEX `Key` (c)`` in a `CREATE TABLE`, but sqlglot treats `` `Unique` ``, `` `Index` `` and `` `Key` `` as constraint keywords and fails. Quoted names must be accepted and round-trip.
