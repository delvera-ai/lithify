Optimizer: the alias at the end of a `PIVOT`/`UNPIVOT` chain names the resulting source, but star expansion and type annotation do not know that name:

```sql
SELECT u.* FROM t UNPIVOT(v FOR m IN (jan, feb)) AS u
-- qualify/optimize: OptimizeError: Unknown table: u   (for CTE sources it expands the pre-pivot columns instead)

WITH c AS (SELECT id, jan, feb FROM t) SELECT * FROM c UNPIVOT(v FOR m IN (jan, feb))
-- id / v are annotated as UNKNOWN
```

Qualified stars over a pivot alias must expand to the post-pivot columns for table, subquery and CTE sources, and columns of an unaliased (UN)PIVOT over a CTE must get the CTE's types.
