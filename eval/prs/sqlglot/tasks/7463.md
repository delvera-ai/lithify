BigQuery dialect: the MODEL-first signatures of the `AI.GENERATE_*` / `ML.GENERATE_*` functions fail to parse:

```python
from sqlglot import parse_one
parse_one("SELECT * FROM ML.GENERATE_TEXT(MODEL `mydataset.gemini_model`, TABLE `mydataset.prompt_table`, STRUCT(0.15 AS temperature))", dialect="bigquery")
# ParseError: Expecting ). Line 1, Col: 61.
```

The same happens for `AI.GENERATE_TEXT(MODEL ..., TABLE ..., STRUCT(...))`, `AI.GENERATE_TABLE(MODEL ..., (SELECT ...), STRUCT(...))`, `AI.GENERATE_BOOL(MODEL ..., ...)` and the related `GENERATE_INT` / `GENERATE_DOUBLE` forms. These documented signatures should parse in BigQuery and round-trip back to equivalent SQL.
