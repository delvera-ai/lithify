T-SQL dialect: nullability in `ALTER COLUMN` is not parsed:

```sql
ALTER TABLE t ALTER COLUMN c INT NOT NULL
```

falls back to an unparsed command, and so do `... INT NULL` and `... INT COLLATE abc NOT NULL`. Parse these into a proper `ALTER` and round-trip them in T-SQL. Dialects that cannot express nullability in an alter-column type change should warn rather than silently drop the constraint (Postgres needs a separate `SET NOT NULL` action).
