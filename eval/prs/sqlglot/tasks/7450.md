BigQuery dialect: pipe syntax (`|>`) does not support the `DISTINCT` operator. This valid BigQuery query fails to parse:

```sql
WITH artificial_data AS (SELECT 1 AS col1 UNION ALL SELECT 1 AS col1)
SELECT col1
FROM artificial_data
|> DISTINCT
```

```
ParseError: Unsupported pipe syntax operator: 'DISTINCT'.
```

Support the `|> DISTINCT` pipe operator (see BigQuery's pipe syntax documentation).
