Expressions: when a function with variable-length arguments is built from an argument list, the extra arguments spill into trailing optional (flag) arguments instead of the variable-length argument:

```python
from sqlglot import exp
chr_ = exp.Chr.from_arg_list([exp.convert(65), exp.convert(66)])
# 66 ends up in chr_.args["charset"]; expected chr_.expressions == [65, 66], charset None, sql "CHR(65, 66)"
```

Variadic arguments must spill into the function's variable-length argument key, for every such function.
