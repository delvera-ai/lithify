Databricks dialect: `IFF` is a synonym for `IF` in Databricks, but sqlglot parses it as an unknown function, so it is not transpiled:

```python
sqlglot.parse_one("IFF(1>0,1,2)", "databricks").sql("duckdb")   # 'IFF(1 > 0, 1, 2)'  (wrong)
sqlglot.parse_one("IF(1>0,1,2)", "databricks").sql("duckdb")    # 'CASE WHEN 1 > 0 THEN 1 ELSE 2 END'
```

`IFF(cond, a, b)` in Databricks should be understood as `IF` and transpile like it to every dialect.
