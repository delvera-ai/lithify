ClickHouse dialect: the higher-order array functions `arrayMap(lambda, arr)` and `arrayFilter(lambda, arr)` are parsed as generic functions, so ClickHouse round-trips are lossy and they don't transpile. Parse them into sqlglot's semantic array function nodes (the same ones other dialects' array transform and filter functions use), and generate them back in ClickHouse form. (Stated requirement: `arrayMap` parses to `exp.Transform` and `arrayFilter` to `exp.ArrayFilter`.)
