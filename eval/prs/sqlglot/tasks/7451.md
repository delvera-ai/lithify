BigQuery dialect: `array_col[offset]` cannot be parsed when `offset` is a column, e.g. the alias from `UNNEST ... WITH OFFSET`, because `OFFSET` is a reserved keyword:

```sql
WITH artificial_data AS (SELECT [1, 2, 3] AS array_col)
SELECT array_col[offset]
FROM artificial_data, UNNEST(array_col) WITH OFFSET AS offset
```

raises `IndexError: list index out of range`, while the same query with `_offset` works. A column named `offset` used as an array index should parse and round-trip.
