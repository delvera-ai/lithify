BigQuery dialect: `LOAD DATA ... FROM FILES(...)` fails to parse:

```sql
LOAD DATA OVERWRITE mydataset.table1
  FROM FILES(format='AVRO', uris = ['gs://bucket/path/file.avro'])
```

```
ParseError: Required keyword: 'inpath' missing for LoadData. Line 3, Col: 6.
```

Support BigQuery's `LOAD DATA [OVERWRITE | INTO [TABLE]] <table> FROM FILES(...)` syntax (parse and generate). The existing `LOAD DATA ... INPATH ...` syntax used by other dialects must keep working.
