Add two convenience methods to sqlglot expressions (`Expr`), familiar from DataFrame libraries: `pipe(func, *args, **kwargs)`, which calls `func(self, *args, **kwargs)` and returns its result, so expression building can stay fluent (`col.pipe(add_val, 5, squared=True)`); and `apply(func)`, which calls `func(self)` and returns `self` unchanged (useful for side effects such as inspection). Both should be typed and documented.
