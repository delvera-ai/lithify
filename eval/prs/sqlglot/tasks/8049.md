Optimizer: `qualify_tables` processes sources shared through lateral references, such as the table in `FROM t, UNNEST(t.arr)`, once per scope that sees them. As a result the `on_qualify` callback fires twice for the same table, and with `canonicalize_table_aliases` aliases are renamed twice and column references are left dangling. Qualify such sources only in the scope that defines them, and never blank out a column's table when an alias is not found in the canonical remapping.
