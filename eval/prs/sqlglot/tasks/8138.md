Python executor: for dialects with typed division (`postgres`, `sqlite`), every division is truncated to an integer regardless of operand types, so `n / 3.0` returns `3` instead of `3.3333...`, silently:

```python
from sqlglot.executor import execute
execute("SELECT n / 3.0 AS r FROM t", dialect="postgres", schema={"t": {"n": "INT"}}, tables={"t": [{"n": 10}]})
```

Only truncate typed division when both operands are integers.
