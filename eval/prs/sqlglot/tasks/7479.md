BigQuery dialect: `AI.EMBED`, `AI.SIMILARITY` and `AI.GENERATE` parse and round-trip, but only as generic function nodes. Give them typed AST nodes so callers can inspect them, while keeping SQL output unchanged:

```python
from sqlglot import parse_one, exp
node = parse_one('SELECT AI.EMBED("hello")', dialect="bigquery").expressions[0]
# node is exp.Dot; node.expression should be a typed AI embed node, not a generic function
```

Unqualified scalar names (without `AI.`) keep their current generic behaviour. (Stated requirement: the typed nodes are `exp.AIEmbed`, `exp.AISimilarity` and `exp.AIGenerate`, reached as the `expression` of the `exp.Dot`.)
