Snowflake dialect: Snowflake's `GET_DDL` outputs `CREATE VIEW ... WITH ROW ACCESS POLICY #unknown_policy AS ...` (with no `ON` clause) when the user may not see the real policy name. This currently falls back to an unparsed command. It should parse into a proper `CREATE` statement and round-trip, and `#unknown_policy` must never be quoted in generated SQL, even with `identify=True`. For normal (non-`#`) policy names the `ON (...)` clause is still required.
