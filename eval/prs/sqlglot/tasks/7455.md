Presto/Trino: when a `SELECT` has several `SEMI` or `ANTI` joins, only every other one is rewritten into `EXISTS` / `NOT EXISTS` by the semi/anti-join elimination transform; the rest leak into the generated SQL as bare `ANTI JOIN` / `SEMI JOIN`, which is invalid in Presto and Trino. For example:

```python
from sqlglot import exp
select = (
    exp.Select().select(exp.column("id", table="t1")).from_("t1")
    .join("t2", on=exp.EQ(this=exp.column("id", table="t1"), expression=exp.column("id", table="t2")))
    .join("t3", join_type="anti", on=exp.EQ(this=exp.column("id", table="t1"), expression=exp.column("id", table="t3")))
    .join("t4", join_type="anti", on=exp.EQ(this=exp.column("id", table="t1"), expression=exp.column("id", table="t4")))
)
print(select.sql(dialect="presto", pretty=True))  # t4 is emitted as a bare ANTI JOIN
```

Every semi and anti join must be rewritten.
