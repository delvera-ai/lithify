Trino dialect, inline SQL UDFs (continuing the existing routine-body support for `CREATE FUNCTION ... BEGIN ... END`): parse and generate `IF` statements inside routine bodies:

```sql
IF cond THEN ...; ELSEIF cond2 THEN ...; ELSE ...; END IF
```

including `ELSEIF` chains of any length, an optional `ELSE`, and nested statement blocks. They must round-trip in Trino.
