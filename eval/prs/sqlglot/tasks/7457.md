BigQuery dialect: the `AI.FORECAST` table-valued function fails to parse with its documented named arguments:

```python
from sqlglot import parse_one
parse_one('SELECT * FROM AI.FORECAST(TABLE citibike_trips, data_col => "num_trips", timestamp_col => "date", horizon => 30)', dialect="bigquery")
# ParseError: Invalid expression / Unexpected token. Line 1, Col: 59.
```

It should parse (with either `TABLE <name>` or a parenthesised query as the first argument) and round-trip back to equivalent SQL. Existing `ML.FORECAST` behaviour must not change.
