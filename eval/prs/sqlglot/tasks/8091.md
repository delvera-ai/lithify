ClickHouse dialect: `MODIFY COLUMN` falls back to an unparsed command instead of an `ALTER`:

```python
for sql in ["ALTER TABLE t MODIFY COLUMN c Int64", "ALTER TABLE t MODIFY COLUMN c Int64 DEFAULT 0"]:
    print(type(sqlglot.parse_one(sql, read="clickhouse")).__name__)   # Command
```

Parse `MODIFY COLUMN` as an alter-column action (type, and default where given) so it is an `Alter`, round-trips in ClickHouse, and can be transpiled.
