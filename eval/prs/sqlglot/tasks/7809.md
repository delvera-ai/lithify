SQLite and other dialects: chained range operators raise a `ParseError`:

```python
sqlglot.parse_one("SELECT 1 NOT IN (0) IN (1)", read="sqlite")
# ParseError: Invalid expression / Unexpected token. Line 1, Col: 22.
```

SQLite runs this query. Parse chains of range operators (`IN`, `NOT IN`, `LIKE`, ...) left to right instead of raising.
