## Issue #7447: BigQuery: can not parse array[offset] where offset is from UNNEST WITH OFFSET because it's a reserved keyword

Thank you for the beautiful and easy to use library!
----
This is quite a dummy query, nevertheless it's an allowed syntax in BigQuery:
```sql
WITH artificial_data AS (
  SELECT
    [1, 2, 3] AS array_col
)
SELECT
  array_col[offset]
FROM
  artificial_data,
  UNNEST(array_col) WITH OFFSET AS offset
```
Output in BigQuery:

<img width="343" height="357" alt="Image" src="https://github.com/user-attachments/assets/4955d35e-abf4-4c9e-bc2c-05d0697d6c8b" />

Sqlglot throws the following error while parsing it:
```bash
IndexError: list index out of range
```

The same query but with `_offset` is parsed with no issues:
```sql
WITH artificial_data AS (
  SELECT
    [1, 2, 3] AS array_col
)
SELECT
  array_col[_offset]
FROM
  artificial_data,
  UNNEST(array_col) WITH OFFSET AS _offset
```
