## Issue #7688: Fail when parsing overloaded DuckDB macro

**Versions**
Python 3.14.5 (tags/v3.14.5:5607950, May 10 2026, 10:43:50) [MSC v.1944 64 bit (AMD64)] on win32
sqlglot==30.8.0

**Fully reproducible code snippet**
```
import sqlglot

# Runs OK
add_2 = sqlglot.parse_one('CREATE OR REPLACE MACRO add_2(a, b) AS a + b;', dialect='duckdb')

# Raises exception
add_x = sqlglot.parse_one(r"""
CREATE MACRO add_x
    (a, b) AS a + b,
    (a, b, c) AS a + b + c;""", read='duckdb')
```
