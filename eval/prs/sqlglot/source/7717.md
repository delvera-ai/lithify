# PR #7717: fix(clickhouse): parse file() as a table function

https://github.com/tobymao/sqlglot/pull/7717

## PR body

Fixes #7715.

TokenType.FILE was missing from FUNC_TOKENS, so `file(...)` in ClickHouse was parsed as a table name followed by alias columns instead of as a table function call.

## Issue #7715: Clickhouse `file` table function parses incorrectly and can't round-trip

**Before you file an issue**
- Make sure you specify the "read" dialect eg. `parse_one(sql, read="spark")` Clickhouse
- Make sure you specify the "write" dialect eg. `ast.sql(dialect="duckdb")` Clickhouse
- Check if the issue still exists on main

**Fully reproducible code snippet**
Please include a fully reproducible code snippet or the input sql, dialect, and expected output.

```python
sqlglot.parse_one("CREATE VIEW myschema.myview (c1 String NOT NULL) AS SELECT c1  FROM file('base/dir/*.parquet', Parquet)", dialect="clickhouse").sql(dialect="clickhouse")

```

Returns this:

```sql
CREATE VIEW myschema.myview (c1 String NOT NULL) AS SELECT c1 FROM file AS _t0("base/dir/*.parquet", Parquet)
```

Note the `AS _t0`

Interestingly the [s3 table function](https://clickhouse.com/docs/sql-reference/table-functions/s3) is understood.

```python
sqlglot.parse_one("CREATE VIEW myschema.myview (c1 String NOT NULL) AS SELECT c1  FROM s3('base/dir/*.parquet', Parquet)", dialect="clickhouse").sql(dialect="clickhouse")

```
return this:
```sql
CREATE VIEW myschema.myview (c1 String NOT NULL) AS SELECT c1 FROM s3('base/dir/*.parquet', Parquet)
```

I came across this while to create DDL for clickhouse views that read parquet files. For now, my workaround is something like this:

```python
    from_clause = exp.From(
        this=exp.Table(
            this=exp.Anonymous(
                this="file",
                expressions=[
                    exp.Literal(this=f"{ctx.file_path}/*.parquet", is_string=True),
                    exp.Column(this=exp.Identifier(this="Parquet", quoted=False)),
                ],
            )
        )
    )
```

## ROOT CAUSE

The AST (remove `.sql(dialect="clickhouse")` at the end is the following) looks like this for the `s3` table function vs the `file` table function

INCORRECT WITH `file` FUNCTION::
```python
From(
      this=Table(
        this=Identifier(this=file, quoted=False),
        alias=TableAlias(
          columns=[
            Identifier(this='base/dir/*.parquet', quoted=True),
            Identifier(this=Parquet, quoted=False)])))
``` 

CORRECT WITH `s3` TABLE FUNCTION
```python
From(
      this=Table(
        this=Anonymous(
          this=s3,
          expressions=[
            Literal(this='base/dir/*.parquet', is_string=True),
            Column(
              this=Identifier(this=Parquet, quoted=False))])))
```
Note `TableAlias` vs `Anonymous`.
