**Official Documentation**

SQLite syntax definitions state that the conflict target consists of a list of **indexed column** elements:

- **[upsert-clause](https://sqlite.org/syntax/upsert-clause.html)**  
  `ON CONFLICT ( indexed-column [, ...] ) ...`

- **[indexed-column](https://sqlite.org/syntax/indexed-column.html)**  
  Can be:
  - `expr`
  - `expr COLLATE collation-name`

- **[expr](https://sqlite.org/syntax/expr.html)**  
  Includes function calls like `lower(name)`, arithmetic, etc.

Because `indexed-column` allows any `expr`, a statement like
```sql
ON CONFLICT (chat_id, lower(name))
```
is legal SQL.
