# PR #8173: Fix: don't crash in exp.cast() when the input is already a cast to INTERVAL (CLAUDE)

https://github.com/tobymao/sqlglot/pull/8173

## PR body

The "don't re-cast if the expression is already the right type" shortcut in `exp.cast()` read `expr.to.this.value`, assuming `this` is a plain type enum. For a complex type such as `INTERVAL`, `to.this` nests another expression (`Interval(unit=HOUR)`), which has no `value`, so the call raised:

```python
import sqlglot.expressions as exp
from sqlglot import parse_one

exp.cast(parse_one("CAST(-1 AS INTERVAL HOUR)"), "BIGINT")
# AttributeError: 'Interval' object has no attribute 'value'
```

It also surfaced during transpilation, e.g. `DATE_ADD(..., CAST(-1 AS INTERVAL HOUR))` to Presto.

This only applies the equivalence check when both types are plain enums, so complex types fall through and get wrapped like any other:

```
CAST(-1 AS INTERVAL HOUR)  ->  CAST(CAST(-1 AS INTERVAL HOUR) AS BIGINT)
```

Closes #8172.

Extended `test_cast` in `tests/test_expressions.py`; `ruff`, `mypy`, and the expression/build/presto suites pass.


## Issue #8172: exp.cast() raises AttributeError when the input is already a cast to INTERVAL

`exp.cast()` crashes with a raw `AttributeError` when the input is already a cast to a complex type such as `INTERVAL`.

**Reproduce**

```python
import sqlglot.expressions as exp
from sqlglot import parse_one

exp.cast(parse_one("CAST(-1 AS INTERVAL HOUR)"), "BIGINT")
# AttributeError: 'Interval' object has no attribute 'value'
```

It also surfaces during transpilation, e.g.:

```python
import sqlglot
sqlglot.transpile("SELECT DATE_ADD(TIMESTAMP '2022-01-01 12:00:00', CAST(-1 AS INTERVAL HOUR))", write="presto")
# same AttributeError
```

The "don't re-cast if the expression is already the right type" shortcut reads `expr.to.this.value`, assuming `this` is a plain type enum. For a complex type like `INTERVAL`, `to.this` nests another expression (`Interval(unit=HOUR)`), which has no `value`.

**Expected**

`exp.cast()` should wrap the value like any other type: `CAST(CAST(-1 AS INTERVAL HOUR) AS BIGINT)`.

sqlglot 30.17.0.
