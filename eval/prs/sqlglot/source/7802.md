## Issue #7799: LATERAL VIEW POSEXPLODE: qualify() cannot resolve a column in the SQL it generates for DuckDB

read="spark"
dialect="duckdb"
Confirmed on main: reproduces on commit 7a0a9abc

Transpiling `LATERAL VIEW POSEXPLODE` from Spark to DuckDB produces SQL that executes correctly in DuckDB, but qualify() raises OptimizeError on that same generated SQL.

The generated DuckDB SQL is:
```sql
SELECT pos, val
FROM t
CROSS JOIN LATERAL (
  SELECT pos - 1 AS pos, val
  FROM UNNEST(t.arr) WITH ORDINALITY AS _t0(val, pos)
)
```
The inner projection `SELECT pos - 1 AS pos` both reads pos (from the _t0(val, pos) table alias) and re-aliases the result to pos. DuckDB resolves this fine, but `qualify_columns` reports Column 'pos' could not be resolved.

**Fully reproducible code snippet**
```py
import sqlglot, duckdb
from sqlglot import parse_one
from sqlglot.optimizer.qualify import qualify

sql = """
SELECT pos, val
FROM t
LATERAL VIEW POSEXPLODE(t.arr) AS pos, val
"""

# 1. Transpile spark -> duckdb
generated = parse_one(sql, read="spark").sql(dialect="duckdb")
print("generated:", generated)
# SELECT pos, val FROM t CROSS JOIN LATERAL (SELECT pos - 1 AS pos, val FROM UNNEST(t.arr) WITH ORDINALITY AS _t0(val, pos))

# 2. The generated SQL executes correctly in DuckDB
con = duckdb.connect()
con.execute("CREATE TABLE t AS SELECT ['a', 'b'] AS arr")
print("duckdb result:", con.execute(generated).fetchall())
# [(1, 'b'), (0, 'a')]

# 3. But qualify() raises on the SQL sqlglot just generated
qualify(
    parse_one(generated, read="duckdb"),
    dialect="duckdb",
    schema={"t": {"arr": "ARRAY<VARCHAR>"}},
)
# sqlglot.errors.OptimizeError: Column 'pos' could not be resolved. Line: 1, Col: 10
```

**Expected output**
qualify() should resolve pos against the WITH ORDINALITY ordinality column in _t0(val, pos) and succeed (as DuckDB itself does), rather than raising OptimizeError.

**Official Documentation**
- DuckDB UNNEST / WITH ORDINALITY: https://duckdb.org/docs/sql/query_syntax/unnest
- Spark LATERAL VIEW / POSEXPLODE: https://spark.apache.org/docs/latest/sql-ref-syntax-qry-select-lateral-view.html
