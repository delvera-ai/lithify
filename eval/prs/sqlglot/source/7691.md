# PR #7691: fix: multiline comment idempotency in connectors [GEMINI]

https://github.com/tobymao/sqlglot/pull/7691

## PR body

This PR fixes an issue where multiline comments attached to connectors (AND/OR) would gain extra whitespace each time they were formatted in pretty mode. It ensures that connectors use the `maybe_comment` helper which correctly handles line break sentinels.
