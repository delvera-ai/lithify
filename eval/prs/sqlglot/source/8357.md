# PR #8357: fix(doris): add 15 missing words to RESERVED_KEYWORDS

https://github.com/tobymao/sqlglot/pull/8357

## PR body

Doris 4.1 reserves these words (the grammar's `DorisLexer.g4` keywords minus `DorisParser.g4`'s `nonReserved` rule), so a bare identifier with any of these names is a parse error on the server — but they were missing from the Doris generator's `RESERVED_KEYWORDS`, so sqlglot rendered such identifiers unquoted: `analyzer`, `asof`, `both`, `char_filter`, `dump`, `layout`, `leading`, `match_condition`, `no_use_mv`, `play`, `token_filter`, `tokenizer`, `trailing`, `try_cast`, `use_mv`.

Each was verified against a live Doris 4.1 frontend: bare use is rejected (`mismatched input '<word>' expecting …`), back-quoted works.

The test loops all 15: `` SELECT `asof` FROM t `` round-trips, and an identifier node carrying the name renders quoted.
