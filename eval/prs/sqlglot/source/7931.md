# PR #7931: feat(optimizer)!: parse and annotate duckdb FROM_HEX

https://github.com/tobymao/sqlglot/pull/7931

## PR body

`UNHEX` and `FROM_HEX` are synonyms in duckdb.

```
memory D SELECT unhex('AA');
┌─────────────┐
│ unhex('AA') │
│    blob     │
├─────────────┤
│ \xAA        │
└─────────────┘
memory D SELECT from_hex('AA');
┌────────────────┐
│ from_hex('AA') │
│      blob      │
├────────────────┤
│ \xAA           │
└────────────────┘
```
