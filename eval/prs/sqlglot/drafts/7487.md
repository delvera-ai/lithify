In sqlglot (clickhouse dialect): Support groupConcat parametric syntax.

This PR fixes an issue reported in Superset (), where this Clickhouse query fails to parse:

```sql
  select
    groupConcat(', ')(part_name) as concatenated
  from system.parts
```
