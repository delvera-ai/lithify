In sqlglot: Add `Expr.{pipe, apply}` methods.

This PR add two new methods to the `Expr` class, `inspect` and `pipe`.

Those are very convenient methods to build expressions with UDF's, and when using polars as an example I always use `pipe` methods to keep things fluent.
The names should feel familiar for users of DataFrame libraries, or Rust.

https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.inspect

## Notes
### Performance
This is primarly for end users, I wouldn't recommend this for internal implementation in hot paths, as in my own benchmarks, where I used functions that weren't doing nothing except return the first argument value, [args and kwargs unpacking can take around 25% longer than plain functions](https://github.com/OutSquareCapital/pyochain/releases), in pure python or [compiled Rust](https://github.com/OutSquareCapital/pyochain/blob/3580351faf64c37d409cf206a07ecc3c936d56e0/rust/src/converters.rs#L10).
