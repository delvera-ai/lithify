In sqlglot (parser dialect): FROM with JOIN subqueries.

## Issue #7596: Fail on duckdb's `FROM first` with joining subqueries

With this query:
```python
import sqlglot

sqlglot.parse_one("""
from (FROM tbl_1) t1
positional join (FROM tbl_2) t2
select
    t1.x as x1,
    t2.x as x2,
""", read='duckdb')
```

It raises error: `ParseError: Invalid expression / Unexpected token`.

When I move select to the beginning, it works.

**Without** subqueries, it works though, for example this query works:
```python
sqlglot.parse_one("""
from tbl_1
positional join tbl_2
select
    tbl_1.x as x1,
    tbl_2.x as x2
""", read='duckdb')
```

Fixes #7596
