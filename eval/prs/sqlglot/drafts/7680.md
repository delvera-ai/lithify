In sqlglot (mysql dialect): Joined table `UPDATE` syntax handling.

## Issue #7679: ParserError when updating multiple tables (MySQL)

This works
```sql
UPDATE
  authors
SET
  authors.deleted_at = now()
```
This fails
```sql
UPDATE
  authors,
  books
SET
  authors.deleted_at = now(),
  books.deleted_at = now()
```
Error:
```logs
sqlglot.errors.ParseError: Invalid expression / Unexpected token. Line 5, Col: 9.
  UPDATE
  authors,
  books
SET
  authors.deleted_at = now(),
  books.deleted_at = now()
```

Fixes #7679
