In sqlglot (sqlite dialect): Render RegexpLike as the REGEXP operator.

## Issue #8080: SQLite: `a REGEXP 'x'` is rewritten to `REGEXP_LIKE(a, 'x')`, which SQLite does not have — even on a sqlite→sqlite round-trip

**Affects:** reproduces on `main` at `9e98d2ca` (2026-08-07) and on the 30.14.0 release. Engine behaviour verified on SQLite 3.53.x (CPython bundled build and sqlean 3.53.4).

**Read/write dialects:** `read="sqlite"` → `dialect="sqlite"`.

## Fully reproducible code example

```python
import sqlglot
print(sqlglot.parse_one("SELECT a REGEXP 'x' FROM t", read="sqlite").sql(dialect="sqlite"))
# SELECT REGEXP_LIKE(a, 'x') FROM t
```

```
sqlite> SELECT 'a' REGEXP 'a';        -- valid syntax; runs whenever a regexp() UDF is registered
sqlite> SELECT REGEXP_LIKE('a','a');  -- no such function: REGEXP_LIKE (SQLite core does not define or document it)
```

No `unsupported()` call is made, so `ErrorLevel.RAISE` does not catch it.

**Documentation:**
- SQLite [`REGEXP` operator](https://www.sqlite.org/lang_expr.html#regexp) — "The REGEXP operator is a special syntax for the regexp() user function"; the operator spelling is the canonical one, and works as soon as an application registers `regexp()` (as sqlean's `regexp` extension and many drivers do)

## Where it happens

`exp.RegexpLike` has no SQLite handling, so the base function fallback renders `REGEXP_LIKE(...)`. The caller's operator spelling — the only spelling SQLite documents — is destroyed on a same-dialect round-trip, replaced by a function SQLite core does not define.

Requested fix: render `exp.RegexpLike` as the `REGEXP` binary operator for SQLite. A PR accompanies this issue.

---

*Investigated with LLM assistance; every engine result above was run against live SQLite.*

Fixes #8080.

SQLite has no `REGEXP_LIKE` function — it exposes `REGEXP` as a binary operator (`X REGEXP Y`, sugar for a user-defined `regexp(Y, X)`). But the SQLite generator falls through to the base `RegexpLike` handler and emits `REGEXP_LIKE(...)`, which is a syntax error in SQLite:

```
$ echo "SELECT 'a' WHERE 'a' REGEXP_LIKE('x');" | sqlite3
Parse error near line 1: near "REGEXP_LIKE": syntax error
```

Before:

```python
>>> sqlglot.transpile("SELECT * FROM t WHERE a REGEXP 'x'", read="sqlite", write="sqlite")
["SELECT * FROM t WHERE REGEXP_LIKE(a, 'x')"]
```

After:

```python
>>> sqlglot.transpile("SELECT * FROM t WHERE a REGEXP 'x'", read="sqlite", write="sqlite")
["SELECT * FROM t WHERE a REGEXP 'x'"]
```
