In sqlglot (qualify dialect): Resolve snowflake positional column refs.

Snowflake supports positional column references such as `t.$1`, where `$N` selects the Nth column from source `t`. Currently, these error with unknown column.

This PR resolves positional references to columns when the source has a complete, unambiguous column list.

If the column list is incomplete (e.g., star, duplicate column names) or query includes PIVOT sources, we retain `$N`. Out of range positions raise OptimizeError unless partial qualification is enabled.
