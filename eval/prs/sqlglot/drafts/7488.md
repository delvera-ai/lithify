In sqlglot (databricks dialect): Support IFF as a synonym for IF.

## Issue #7347: Databricks IFF function is not transpiled correctly

In Databricks, IFF is a synonym to 'IF' function:

```
>>> a = "IFF(1>0,1,2)"
>>> sqlglot.parse_one(a, "databricks")
Anonymous(
  this=IFF,
  expressions=[
    GT(
      this=Literal(this=1, is_string=False),
      expression=Literal(this=0, is_string=False)),
    Literal(this=1, is_string=False),
    Literal(this=2, is_string=False)])
>>> sqlglot.parse_one(a, "databricks").sql("snowflake")
'IFF(1 > 0, 1, 2)'
>>> sqlglot.parse_one(a, "databricks").sql("duckdb")
'IFF(1 > 0, 1, 2)'
```

```
>>> a = "IF(1>0,1,2)"
>>> sqlglot.parse_one(a, "databricks").sql("duckdb")
'CASE WHEN 1 > 0 THEN 1 ELSE 2 END'
>>> sqlglot.parse_one(a, "databricks").sql("snowflake")
'IFF(1 > 0, 1, 2)'
```

## Summary

- Adds `"IFF": exp.If.from_arg_list` to `DatabricksParser.FUNCTIONS`, so `IFF(cond, true, false)` is parsed to `exp.If` and transpiles correctly to all target dialects
- Follows the same pattern already used by the Snowflake parser

Fixes #7347
