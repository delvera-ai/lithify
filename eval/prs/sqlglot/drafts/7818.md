In sqlglot (hive dialect): PARSE_JSON and TO_JSON roundtrip.

Preserve roundtrip for (`TO_JSON` is single arg in hive):
```
> SELECT TO_JSON(PARSE_JSON('{"key": 123}'));
+--------------+
|     _c0      |
+--------------+
| {"key":123}  |
+--------------+
```

`PARSE_JSON` returns the `VARIANT` style value like databricks.
