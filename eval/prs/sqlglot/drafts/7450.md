In sqlglot (bigquery dialect): Pipe syntax DISTINCT.

## Issue #7449: BigQuery: sqlglot fails to parse BigQuery pipe syntax (|>) with DISTINCT operator

Once again, thanks a lot for the amazing library!

----
Example of a valid query that `sqlglot` fails to parse:
```sql
WITH artificial_data AS (
 SELECT 1 AS col1
 UNION ALL
 SELECT 1 AS col1
)

SELECT col1
FROM artificial_data
|> DISTINCT
```
BigQuery output:

Sqlglot error message:
```bash
ParseError: Unsupported pipe syntax operator: 'DISTINCT'.. Line 10, Col: 11.
  ial_data AS (
 SELECT 1 AS col1
 UNION ALL
 SELECT 1 AS col1
)

SELECT col1
FROM artificial_data
```

Fixes #7449
