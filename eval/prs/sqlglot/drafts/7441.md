In sqlglot (sqlite dialect): Support PRAGMA full syntax.

## Issue #7437: A Sqlite parser error caused by a specific value "on"

When I'm trying to parse the query below, a error occurs:
```python
import sqlglot
sql = """PRAGMA full_column_names=on;;"""
ast = sqlglot.parse_one(sql, read = "sqlite")
print(ast.sql())
```
error messages:
```
sqlglot.errors.ParseError: Required keyword: 'expression' missing for <class 'sqlglot.expressions.core.EQ'>. Line 1, Col: 27.
  PRAGMA full_column_names=on;
```
However, when the value is not "on" but other values such as "off", "1", "2" etc. The query can be parsed normally.

Fixes #7437

[sqlite PRAGMA](https://sqlite.org/pragma.html)
