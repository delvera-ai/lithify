In sqlglot (tsql dialect): Parse EXEC return status parameter (CLAUDE).

## Issue #7834: tsql: EXECUTE @return_status = proc @args fails to parse (regression since v29.0.0)

**Before you file an issue**

**Fully reproducible code snippet**

```python
import sqlglot

sqlglot.parse("EXEC @RC = dbo.MyProc @a, @b;", read="tsql")

Raises:

sqlglot.errors.ParseError: Required keyword: 'this' missing for <class 'sqlglot.expressions.core.EQ'>. Line 1, Col: 23.
EXEC @RC = dbo.MyProc @a, @b;

The plain form without the return-status assignment parses fine:

sqlglot.parse("EXEC dbo.MyProc @a, @b;", read="tsql")  # OK

Also fails with no arguments at all, and with the unabbreviated keyword:

sqlglot.parse("EXEC @RC = dbo.MyProc;", read="tsql")            # ParseError
sqlglot.parse("EXECUTE @RC = dbo.MyProc @a, @b;", read="tsql")  # ParseError

**Official Documentation**

[EXECUTE (Transact-SQL)](https://learn.microsoft.com/en-us/sql/t-sql/language-elements/execute-transact-sql?view=sql-server-ver17) — EXEC/EXECUTE supports an optional @return_status =  prefix that captures the stored procedure's return code:

[ [ EXEC [ UTE ] ]
    {
      [ @return_status = ]
      { module_name [ ;number ] | @module_name_var }
      ...

This is standard, widely used syntax, and sqlglot's tsql dialect fails to parse it.

Fixes #7834

T-SQL `EXECUTE`/`EXEC` allows capturing a procedure's return status: `EXEC @return_status = dbo.MyProc @a, @b`. `_parse_execute` parsed the first token as the procedure name via `_parse_table`, so `@return_status` was taken as the target and the following `=` raised `ParseError: Required keyword: 'this' missing for EQ`.

This optionally consumes a leading `@param =` as the return-status target before parsing the procedure. If a parameter is present but not followed by `=`, the parser retreats so the existing `EXEC @param` forms are unaffected. The new `return_status` arg is emitted by the T-SQL generator, so the statement round-trips.

Verified round-trips (and that the plain forms are unchanged):

```
EXEC @RC = dbo.MyProc @a, @b        -> EXECUTE @RC = dbo.MyProc @a, @b
EXECUTE @return_status = dbo.MyProc -> EXECUTE @return_status = dbo.MyProc
EXEC dbo.MyProc @a, @b              -> EXECUTE dbo.MyProc @a, @b
EXEC sp_executesql @stmt           -> EXECUTE sp_executesql @stmt
```
