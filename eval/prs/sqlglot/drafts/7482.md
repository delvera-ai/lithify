In sqlglot (bigquery dialect): Support LOAD DATA FROM FILES syntax.

## Issue #7480: BigQuery: LOAD DATA ... FROM FILES(...) raises ParseError: Required keyword 'inpath' missing

```sql
LOAD DATA OVERWRITE mydataset.table1
  FROM FILES(
    format='AVRO',
    uris = ['gs://bucket/path/file.avro']
  )
```

Error message:
```bash
ParseError: Required keyword: 'inpath' missing for <class 'sqlglot.expressions.dml.LoadData'>. Line 3, Col: 6.
  
LOAD DATA OVERWRITE mydataset.table1
  FROM FILES(
    format='AVRO',
    uris = ['gs://bucket/path/file.avro']
  )
```

## Summary:

- keep existing LOAD DATA ... INPATH ... parsing behavior by falling back to the base parser when FROM FILES is not matched
- make LoadData.inpath optional and add optional files payload for BigQuery form
- add BigQuery generator override to emit LOAD DATA [OVERWRITE|INTO TABLE ...] FROM FILES(...)
- add BigQuery regression tests for both OVERWRITE ... FROM FILES(...) and INTO TABLE ... FROM FILES(...)

Closes #7480.
