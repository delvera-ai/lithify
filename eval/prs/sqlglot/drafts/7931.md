In sqlglot (optimizer dialect): Parse and annotate duckdb FROM_HEX.

`UNHEX` and `FROM_HEX` are synonyms in duckdb.

```
memory D SELECT unhex('AA');
┌─────────────┐
│ unhex('AA') │
│    blob     │
├─────────────┤
│ \xAA        │
└─────────────┘
memory D SELECT from_hex('AA');
┌────────────────┐
│ from_hex('AA') │
│      blob      │
├────────────────┤
│ \xAA           │
└────────────────┘
```
