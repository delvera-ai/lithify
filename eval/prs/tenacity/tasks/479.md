Bug (regression since 8.3.0): a function decorated with `@retry` that is called recursively from within its own retry loop (for example a retry predicate that calls the decorated function again to perform a fix-up) breaks the outer call: the outer retry loop does not complete correctly because the inner call shares and overwrites its retry context. Each call of a decorated function must get its own independent retry context, so recursive and nested calls behave like they did in 8.2.3.
