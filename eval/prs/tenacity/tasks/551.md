Feature: `AsyncRetrying` should be usable to retry a *synchronous* function while still sleeping asynchronously (so the event loop is not blocked), and the `@retry` decorator should accept an async `sleep` function even when the decorated function is synchronous: in that case the decorated function becomes awaitable and retries with the async sleep. Existing synchronous behaviour with a synchronous sleep must not change. Python 3.9 support may be dropped.
