# PR #334: Return non-finite floats unchanged from `naturaldelta`

https://github.com/python-humanize/humanize/pull/334

## PR body

## Summary
Closes #333.

`naturaldelta()`'s docstring says values it cannot convert to a `timedelta` are returned unchanged, and `float("nan")` already is. But `float("inf")` / `float("-inf")` raised an uncaught `OverflowError` (from `int(value)`) instead of being returned unchanged like `nan`:

```pycon
>>> humanize.naturaldelta(float("nan"))
'nan'
>>> humanize.naturaldelta(float("inf"))
OverflowError: cannot convert float infinity to integer   # before
'inf'                                                      # after
```

## Fix
Catch `OverflowError` and return the value unchanged **only when it is non-finite**. A too-large *finite* value — whose `OverflowError` comes from `timedelta(seconds=...)` — is still re-raised, preserving the documented `Raises: OverflowError` contract:

```python
except OverflowError:
    if not math.isfinite(value):
        return str(value)
    raise
```

- `test_naturaldelta_non_finite` — asserts `nan`/`inf`/`-inf` return `"nan"`/`"inf"`/`"-inf"`.
- `test_naturaldelta_too_large_value_raises` — locks in that a too-large finite value (`1e30`) still raises `OverflowError`.

## Issue #333: naturaldelta() raises OverflowError on float('inf') instead of returning it unchanged

### Summary
`naturaldelta()` documents that a non-finite float value is "returned unchanged." `nan` is handled (its `int()` raises `ValueError`, which is caught), but `float('inf')`/`float('-inf')` raise an uncaught `OverflowError` from `int(value)`, because the `except (ValueError, TypeError)` clause omits `OverflowError`. The behavior is asymmetric and contradicts the docstring.

### Reproduction
```python
import humanize

print(humanize.naturaldelta(float("nan")))  # 'nan'   (handled)
print(humanize.naturaldelta(float("inf")))  # OverflowError: cannot convert float infinity to integer
```

### Expected
`naturaldelta(float("inf"))` returns the value unchanged (symmetric with `nan`), per the docstring.

### Actual
Uncaught `OverflowError`.

### Fix sketch
Include `OverflowError` in the caught exceptions around the `int(value)` guard (time.py ~L149).

### Environment
humanize 4.15.1.dev (main @ c2c410c), Python 3.12.
