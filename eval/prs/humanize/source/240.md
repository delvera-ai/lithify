## Issue #239: naturalsize output changed between 4.11.0 and 4.12.0

Possibly a result of https://github.com/python-humanize/humanize/pull/218, we are seeing that the output has changed:

1. podman run -it python bash
2. python -m pip install humanize==4.11.0
3. python -c "import humanize; print(humanize.naturalsize(1.123456789))"
> 1 Bytes
4. python -m pip install humanize==4.12.0
5. python -c "import humanize; print(humanize.naturalsize(1.123456789))"
> 1.123456789 Bytes

Expected behaviour is that output would not change in a minor version or that it would be [documented in the release notes](https://github.com/python-humanize/humanize/releases/tag/4.12.0).
