# PR #272: `naturaldelta`: round the value to nearest unit that makes sense

https://github.com/python-humanize/humanize/pull/272

## PR body

naturaldelta used to always round down. We want instead to round to the nearest unit that makes sense.

Fixes #174 

Changes proposed in this pull request:

* naturaldelta rounds to the nearest value that makes sense
* correctly handle cases where we are rounding up, leading to a higher unit: 60 minutes -> one hour
* timedelta also round to the nearest value that makes sense



## Issue #174: `humanize.naturaldelta()` always rounds down

### What did you do?
```py
import humanize

humanize.naturaldelta(10799)
```
Note that this is exactly one second below 3 hours.

### What did you expect to happen?
It should say 3 hours.

### What actually happened?
It says 2 hours.

### What versions are you using?

* OS: Debian 12
* Python: 3.11.2
* Humanize: 4.9.0
